# 直连模型与最佳努力恢复

**Status: accepted**

浏览器扩展直接调用用户配置的 OpenAI-compatible 模型服务，不经开发方服务器；书签移动遵循“确认后执行、失败停止、基于快照最佳努力恢复”的模型。这样将书签数据接收方明确交给用户选择，并承认浏览器书签 API 不提供事务性批量移动：恢复不得覆盖外部修改，也不得伪装成原子回滚成功。

## Considered Options

- 由开发方提供代理服务：被拒绝，因为会扩大隐私边界、需要账号和服务端存储或转发。
- 失败后强制恢复全部节点：被拒绝，因为用户可能已在部分执行后手动修改书签，强制移动会覆盖后续意图。
