# 采用元数据最小化的隐私边界

**Status: accepted**

模型只接收书签标题、相对分类范围的文件夹路径和移除用户名、密码、query、hash 后的 HTTP(S) URL；不抓取网页正文、meta description 或其他页面内容。模型服务由用户配置，扩展直连且不经过开发方服务器。这样保留分类所需的基本语境，同时避免扩大权限、抓取范围和敏感 URL 泄露面。

## Considered Options

- 抓取网页正文或 meta description：被拒绝，因为会增加权限、跨域、缓存、失效网页和隐私风险。
- 发送完整 URL：被拒绝，因为 query、hash 和凭据可能包含搜索词、令牌或个人信息。
- 通过开发方服务器代理：被拒绝，因为开发方会成为书签元数据接收方。
