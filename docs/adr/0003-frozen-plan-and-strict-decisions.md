# 冻结分类方案并使用严格分类裁决协议

**Status: accepted**

模型先生成分类方案，插件为分类生成自己的稳定 ID；后续批次只能引用冻结的分类 ID。每个请求中的书签 ID 必须且只能出现一次，并得到 `assign` 到合法分类或显式 `pending` 的裁决。这样分类名称可在预览中编辑而不会改变归属身份，也不会因模型省略低置信度书签而把正常的待确认状态误判为协议成功。

## Considered Options

- 每批独立生成分类：被拒绝，因为批次之间会产生重复或冲突分类。
- 使用分类名称或数组位置作为引用：被拒绝，因为名称可编辑、可重复，数组位置也不适合作为稳定标识。
- 省略低置信度书签：被拒绝，因为遗漏 ID 无法与协议错误区分。
